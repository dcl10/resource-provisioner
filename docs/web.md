# Web app

The Next.js frontend in `web/`: the chat page, the requests list and detail pages, and the admin Users page.

## Running it

From `web/`, with Node 22 and Corepack enabled (`corepack enable`), so you get the npm version pinned in
`package.json`:

```bash
npm install          # also installs the Husky pre-commit hook
npm run dev          # http://localhost:3000
npm run lint         # ESLint, including Prettier and import order
npm run format       # Prettier --write
npm test             # Vitest, once
npm run build        # production build to .next/standalone
```

The pre-commit hook runs `lint-staged`: `eslint --fix` on staged TS/JS files and Prettier on JSON, CSS and Markdown.

## Layout

```
web/
├── app/
│   ├── layout.tsx          # fonts, <Providers>, <AppShell>
│   ├── page.tsx            # "/" redirects to /chat
│   ├── chat/page.tsx       # chat (#18)
│   └── requests/page.tsx   # requests list (#19)
├── components/
│   ├── providers.tsx       # next-themes, TanStack Query, tooltips, sonner Toaster
│   ├── app-shell.tsx       # header with nav and theme toggle, around every page
│   ├── main-nav.tsx        # Chat, Requests, and Users (admins only)
│   ├── theme-toggle.tsx    # light / dark / system
│   └── ui/                 # shadcn primitives, generated by the CLI, never hand-edited
└── lib/utils.ts            # shadcn's cn() helper
```

The Users link is hidden until sign-in (#7) tells the shell whether the user has `rp-admin`.

## Stack

| Concern | Library | Notes |
| --- | --- | --- |
| Framework | `next` 16, `react` 19, TypeScript | App Router, `output: 'standalone'`, Cache Components on |
| Styling | `tailwindcss` v4 via `@tailwindcss/postcss`, `tw-animate-css` | theme tokens in `app/globals.css` |
| Components | `shadcn` CLI, style `base-nova` (`@base-ui/react`), `class-variance-authority`, `cn` | `cn` replaces `clsx` + `tailwind-merge` in current shadcn |
| Icons | `lucide-react` | the only icon set |
| Theme | `next-themes` | class-based dark mode |
| Forms | `react-hook-form` + `zod` + `@hookform/resolvers`, shadcn `field` | `base-nova` has no `form` component |
| Tables | `@tanstack/react-table` | shadcn data-table pattern |
| Toasts | `sonner` | `toast()` from anywhere |
| Chat text | `react-markdown` + `remark-gfm` + `rehype-sanitize` | never `rehype-raw`: assistant output is untrusted |
| Client data | `@tanstack/react-query` | polling, mutations, cache invalidation |
| Tests | `vitest`, Testing Library, `jsdom`, `@vitejs/plugin-react` | colocated `*.test.tsx` |
| Lint and format | `eslint` + `eslint-config-next`, `prettier`, `eslint-plugin-simple-import-sort`, `husky` + `lint-staged` | |

Left out on purpose: milkdown, cmdk, motion, nuqs, react-icons.

## shadcn components

Installed: alert-dialog, avatar, badge, button, card, dialog, dropdown-menu, field, input, label, scroll-area, select,
separator, skeleton, sonner, table, tabs, textarea and tooltip. Add more with `npx shadcn@latest add <name>` from
`web/`.

Base UI components compose through the `render` prop rather than Radix's `asChild`:

```tsx
<DropdownMenuTrigger render={<Button variant="ghost" size="icon" />}>…</DropdownMenuTrigger>
```
